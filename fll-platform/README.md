# منصة فريق FLL 🤖

منصة تدريب خاصة بفريق FIRST LEGO League. بتشتغل على الإنترنت بشكل مستقل، وأي حد معاه الرابط وحسابه يقدر يدخل من أي موبايل أو لابتوب من غير حساب Claude.

## الأقسام

| القسم | فيه ايه |
|---|---|
| **Programming** | مساعد AI بيشرح الكود سطر بسطر ويساعد في الـ PID، ومعاه **PID Lab**: تغيّر Kp و Ki و Kd وتشوف الروبوت ماشي على الخط ورسمة الـ error. |
| **Robot Game** | محاكي طاولة FLL فيه روبوت كامل: 2 Large motors للحركة، 2 Medium motors للأذرع، Color sensor و Distance sensor و Force sensor و Motion sensor. بتسحب ألوان وعقبات من شريط الأدوات وتحطها على الطاولة، وتكتب الكود بـ Python أو JavaScript وتشغّله. فيه كمان مساعد AI بيشوف الكود والطاولة، وتايمر 2:30، وحفظ الطاولات للفريق. |
| **Task Submissions** | الطالب بيبعت التاسك PDF للكوتش نور أو لزمايله عشان يساعدوه. الكوتش بس هي اللي تقدر تقيّم (درجة من 10 + مقبول/محتاج تعديل + ملاحظات). فيه تعليقات ونسخ جديدة وإشعارات. |
| **Mechanics** | ترفع PDF أو صور للروبوت، والـ AI يقيّم التصميم ويشرح طريقة عمله وبناءه خطوة بخطوة. |
| **Core Values** | مساعد AI متخصص في الـ Core Values والتحضير للـ judging. |
| **الجروبات** | لكل قسم جروب للفريق والكوتش، وجروب عام. الرسايل بتوصل على طول، وتقدر تبعت PDF وصور. |

## خطوات تشغيل المنصة على الإنترنت (مجانًا)

محتاجين 4 حسابات مجانية: **Google** (لمفتاح الـ AI)، **MongoDB Atlas** (لحفظ البيانات)، **GitHub** (لرفع الملفات)، و **Render** (للاستضافة). الخطوات دي بتاخد حوالي 20 دقيقة مرة واحدة بس.

### 1) مفتاح Gemini للـ AI (مجاني)
1. ادخل على https://aistudio.google.com بحساب جوجل (لازم صاحب الحساب يكون 18 سنة أو أكبر، يعني الكوتش).
2. دوس **Get API key** ← **Create API key**.
3. انسخ المفتاح واحتفظ بيه (هنحطه في Render في الخطوة 4).

> الخطة المجانية ليها حد في عدد الأسئلة في الدقيقة واليوم، وده كفاية لفريق صغير. لو ظهرت رسالة "الحد المجاني اتخطى" استنوا دقيقة. ماتبعتوش للـ AI بيانات شخصية.

### 2) قاعدة بيانات MongoDB Atlas (مجانية، عشان الرسايل والتاسكات ماتضيعش)
1. اعمل حساب على https://www.mongodb.com/cloud/atlas/register
2. اعمل **Cluster** جديد واختار الخطة **Free** (M0)، وأي منطقة قريبة.
3. من **Database Access** ← **Add New Database User**: اكتب اسم مستخدم وكلمة سر (يفضل حروف وأرقام بس) واحفظهم.
4. من **Network Access** ← **Add IP Address** ← **Allow access from anywhere** (يعني `0.0.0.0/0`) ← Confirm. (مهم عشان Render يقدر يوصل.)
5. من **Database** ← **Connect** ← **Drivers** ← انسخ الـ connection string، شكله كده:
   `mongodb+srv://USER:<db_password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority`
6. غيّر `<db_password>` بكلمة السر اللي عملتها في الخطوة 3.

### 3) ارفع الملفات على GitHub
1. اعمل حساب على https://github.com
2. دوس **+** ← **New repository**، سمّيه مثلاً `fll-platform` واختار **Private** ← **Create repository**.
3. دوس **uploading an existing file**، وفك ضغط ملف المنصة واسحب **كل الملفات والفولدرات اللي جواه** (مش الفولدر نفسه) لصفحة GitHub ← **Commit changes**.
   - اتأكد إن `package.json` و `server.js` و `render.yaml` ظاهرين في الصفحة الرئيسية للـ repository.

### 4) شغّل المنصة على Render
1. اعمل حساب على https://render.com بزرار **GitHub**.
2. دوس **New +** ← **Blueprint** ← اختار الـ repository بتاعك ← **Connect**.
3. Render هيقرأ ملف `render.yaml` ويطلب منك قيمتين:
   - `GEMINI_API_KEY` ← حط مفتاح جوجل من الخطوة 1.
   - `MONGODB_URI` ← حط الـ connection string من الخطوة 2.
4. دوس **Apply** واستنى لحد ما يكتب **Live** (أول مرة بتاخد كام دقيقة).
5. هتلاقي رابط المنصة فوق، شكله كده: `https://fll-team-platform.onrender.com` — ده الرابط اللي هتبعته للفريق. ✅

> **بدون Blueprint؟** دوس **New +** ← **Web Service** ← اختار الـ repository، وخلي Build Command = `npm install` و Start Command = `npm start` والخطة **Free**، وضيف في **Environment** المتغيرات: `GEMINI_API_KEY` و `MONGODB_URI` و `JWT_SECRET` (أي كلام طويل عشوائي) و `NODE_VERSION` = `22`.

### 5) ابعت الحسابات للفريق
كل واحد بيدخل بالـ username وكلمة السر بتوعه (موجودين في ملف الحسابات اللي اتبعتلك لوحده). بعد أول دخول، أي حد يقدر يغيّر كلمة السر من صفحة **حسابي**، والكوتش نور تقدر تعمل كلمة سر جديدة لأي طالب نسي كلمة السر.

## ملاحظات مهمة
- **الخطة المجانية في Render بتنام** لو محدش فتح المنصة 15 دقيقة، فأول ما حد يفتحها بعد كده بتاخد حوالي دقيقة عشان تصحى. ده عادي.
- لو ماحطتش `MONGODB_URI`، المنصة هتشتغل بس البيانات هتضيع كل ما Render يعيد التشغيل (وهيظهر تنبيه للكوتش في الصفحة الرئيسية).
- كلمات السر متخزنة **مشفّرة** (bcrypt) في `seed-users.json`، ومع كده خلي الـ repository **Private**.
- الحسابات بتتعمل أول مرة بس لما قاعدة البيانات تكون فاضية. لو عايز تغيّر الأسماء، عدّل `seed-users.json` قبل أول تشغيل.
- المساعد الذكي بيشرح ويوجّه ومش بيحل التاسكات بدل الطلاب، عشان ده من قواعد وروح FLL.

## تشغيل المنصة على جهازك (اختياري)
1. نزّل Node.js نسخة 22 من https://nodejs.org
2. في فولدر المنصة: انسخ `.env.example` باسم `.env` وحط فيه `GEMINI_API_KEY` (و`MONGODB_URI` لو عايز).
3. شغّل:
   ```
   npm install
   npm start
   ```
4. افتح http://localhost:3000 — ولو عايز تجرب من غير مفتاح AI شغّل `npm run dev` (ردود تجريبية).

| الـ PDF مش ظاهر على الموبايل | دوس زرار "فتح" جنب الملف. |
| Python في المحاكي بطيء أول مرة | طبيعي، بيتحمّل مرة واحدة (10–20 ثانية) وبعد كده بيبقى سريع. |
